## Usage in ChromeCRISPR

This project relies on these software packages for:

1. **Model Development**: PyTorch for neural network implementation
2. **Hyperparameter Optimization**: Optuna for Bayesian optimization
3. **Data Processing**: NumPy, Pandas, SciPy for data manipulation
4. **Machine Learning**: Scikit-learn for traditional ML baselines
5. **Visualization**: Matplotlib, Seaborn, Plotly for results visualization
6. **Biological Data**: Biopython for sequence processing
7. **Progress Tracking**: TQDM for training progress bars
8. **Model Analysis**: TorchInfo for architecture visualization
9. **Testing**: pytest for automated testing
10. **Code Quality**: Black for code formatting

All citations should be included when using ChromeCRISPR in publications or presentations.
